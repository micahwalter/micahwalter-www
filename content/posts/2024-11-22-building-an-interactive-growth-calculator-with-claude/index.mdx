I asked Anthropic's [Claude](http://claude.ai) to build me a simple, interactive calculator as a static website for looking at year over year growth. It's simple math, but nice to have something that shows a chart and I can easily click on and play with.

This whole process took less than ten minutes, including the adjustments I asked for and fixes I had to have Claude do. It was interesting to see which frameworks and libraries Claude chose. It went with [React](https://react.dev/) and eventually I asked it to consider [chart.js](https://www.chartjs.org/).

It's also interesting that Claude's Artifacts capability often produces just the Javascript you ask for, and embeds that into a web browser behind the scenes, and sometimes it gives you the full HTML, in which case you have to ask it to kindly add that HTML, if you need it.

Here's my conversation with Claude 3.5 Sonnet :

> Me: I'd like to build a simple interactive static website where users can adjust some settings and calculate when a company will reach a desired run rate. Controls should be:
> 
> 1.  current run rate
> 2.  current YoY growth percentage
> 3.  forecasted increase to YoY growth as percentage increase or decrease
> 
> I'd like to show the math and also a chart expressing the overall growth

> Claude: This calculator:
> 
> -   Shows time to reach 10x current run rate
> -   Updates calculations in real-time
> -   Displays growth trajectory in a line chart
> -   Formats numbers for readability
> -   Caps projections at 20 years
> 
> Would you like any adjustments to the calculations or visualization?

```
import React, { useState, useCallback } from 'react';
import { Card, CardHeader, CardTitle, CardContent } from '@/components/ui/card';
import { LineChart, Line, XAxis, YAxis, CartesianGrid, Tooltip } from 'recharts';
import { Input } from '@/components/ui/input';
import { Label } from '@/components/ui/label';

const GrowthCalculator = () => {
  const [currentRunRate, setCurrentRunRate] = useState(1000000);
  const [currentGrowth, setCurrentGrowth] = useState(20);
  const [growthChange, setGrowthChange] = useState(0);

  const calculateGrowth = useCallback(() => {
    const targetRunRate = 10 * currentRunRate; // 10x current run rate
    let years = 0;
    let runRate = currentRunRate;
    let growth = currentGrowth;
    const data = [{
      year: years,
      runRate: runRate
    }];

    while (runRate < targetRunRate && years < 20) {
      years++;
      growth = growth + growthChange;
      runRate = runRate * (1 + growth / 100);
      data.push({
        year: years,
        runRate: Math.round(runRate)
      });
    }

    return {
      years,
      data,
      finalRunRate: runRate
    };
  }, [currentRunRate, currentGrowth, growthChange]);

  const { years, data, finalRunRate } = calculateGrowth();

  return (

            />

};
```
