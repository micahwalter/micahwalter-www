Exploring Generative AI

[https://martinfowler.com/articles/exploring-gen-ai.html](https://martinfowler.com/articles/exploring-gen-ai.html)

> Previously, developers could rely on Copilot for minor assistance, such as generating a few lines of code within a single method. Now, the tool can tackle larger tasks, simultaneously editing multiple files and implementing several steps of a larger plan. This represents a step change for coding assistance workflows.
> 
> Birgitta Böckeler

On Martin Fowler's website.

I've also been exploring GenAI in code editors lately. It started with [Amazon Q Developer](https://aws.amazon.com/q/developer/) (previously Code Whisperer) and more recently [GitHub Copilot](https://github.com/features/copilot), and also the AI capabilities of on the command line within [Warp](https://www.warp.dev/).

But to be honest, I've had the most success so far using [Claude](http://claude.ai) in the browser. I'm not sure why, but I find that separating what's going on in my code editor from the sketchbook/chat nature of Claude in the browser is quite nice.
